# Constellations of the Present

**Artist:** Andrea Cacioppo
**Institution:** Politecnico di Milano
**Year:** 2026
**Format:** Interactive web artwork (public URL, single-page, browser-based)
**Theme:** ELYAH — Constellating Place, Data, Identity

## Concept Statement (≤ 250 words)

The sky is the original shared surface: the same stars for everyone, everywhere. Constellations of the Present rebuilds that shared surface for the network age — a collective sky that exists only in the living present, built from moments instead of profiles.

The work is a live interactive website. Each visitor's presence is sensed entirely on their own device: the camera reads expression, attention, and engagement in real time. That reading is quantized and immediately reduced to a non-reversible hash — a "moment-hash" — seeded with a random nonce. Only this anonymous code leaves the device. The code places a star in a constellation shared by everyone who is looking up at the same moment. Stars flicker with the uncertainty of the moment that created them, grow while that moment is held, and fade back into the dark when the person looks away. Connection lines form only between people present in the same instant — a web of the now.

Nothing raw is ever transmitted, stored, or logged in any form that could identify a person. The artwork is a working proof of its own thesis: that a collective can be built without capturing anyone — a sky without capture.

In an age defined by surveillance and data extraction, the piece asks a quiet question: what would a public feel like if it collected nothing, remembered nothing, and existed only in the present tense?
